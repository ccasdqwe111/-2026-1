# 去授权2026全新「悬赏任务发布平台源码」拉新地推系统源码发布

源码获取：ym7k.com/19116/

这套是对标众人帮、趣闲赚模式的悬赏兼职 + 地推拉新二合一源码，**去授权无域名绑定、无加密授权码限制**，私有化独立部署，Uniapp 前端 + ThinkPHP 后端，支持 H5、微信小程序、APP 打包，主打 APP 拉新、注册下载、地推核验、线上悬赏接单，适合地推团队、渠道商、任务联盟搭建自己的任务平台，可深度二开。

## ✅ 技术架构

- 前端：UniApp，一套代码打包小程序、H5、安卓 APP，自适应手机端
- 后端：ThinkPHP，PHP7.4+、MySQL5.7、Redis 缓存
- 特色卖点：**去授权版本**，不锁域名、不绑定服务器，不用授权密钥，拿到源码即可多服务器部署
- 存储：阿里云 OSS / 腾讯云 COS
- 配套：高德 / 百度定位、短信通知、微信支付、易支付、钱包代付、图片水印
- 后台：Vue 管理后台，权限分级，支持多审核员、财务子账号

## ✅ 用户端核心功能

1. **任务大厅分类**
任务类型全覆盖：APP 注册拉新、扫码下载、注册实名、小程序授权、地推线下核验、问卷、关注点赞、评论助力、游戏试玩；后台可自定义分类、图标、排序置顶。
2. **任务发布 & 接单流程**
发布方充值预付赏金，设置任务单价、名额、有效期、审核时效、提交凭证要求（截图、录屏、定位照片）；接单用户领取任务，按指引完成后上传凭证提交审核；支持申诉通道，审核驳回可重新提交。
3. **地推专属 LBS 定位核验（重点）**
地推任务开启定位校验，限定任务可做区域、打卡地点；提交材料自带 GPS 水印、时间水印，防止异地刷量、跑单作弊，非常适合线下地推团队落地。
4. **钱包资金体系**
余额、可提现收益、冻结赏金、预付保证金；支持微信 / 支付宝提现，后台自定义提现门槛、手续费、提现周期；资金流水全部留痕。
5. **裂变师徒分佣体系**
邀请好友生成专属推广海报、邀请码；下级做任务、发布任务，上级拿提成奖励；师徒关系永久绑定，有邀请排行榜、每日邀请奖励。
6. **会员增值体系**
VIP 会员：发布任务更低手续费、任务优先曝光、提现免手续费、可发布更多任务；后台自定义会员套餐价格与权益。
7. **消息通知**
任务审核结果、收益到账、提现状态、系统公告、申诉提醒，短信 + 站内消息双通知。
8. **信用分风控**
用户信用分机制，频繁恶意提交、刷单驳回会扣信用分；低分限制接单、限制发布任务，降低平台刷量风险。

## ✅ 管理后台功能

1. 用户管理：账号封禁、实名审核、信用分调整、用户余额手动调整
2. 任务管理：全部任务审核、下架违规任务、批量设置、查看任务提交凭证、批量驳回 / 通过
3. 资金管理：充值订单、提现工单审核、平台抽成配置、保证金管理、财务对账导出 Excel
4. 风控配置：敏感词库、防刷规则、定位水印开关、申诉流程配置
5. 广告运营：首页轮播、弹窗公告、任务置顶竞价、首页推荐位收费
6. 分销师徒设置：分佣比例开关、层级设置、奖励规则配置
7. 系统配置：支付通道、短信、OSS、协议文案（隐私协议、用户协议、任务规则）

## ✅ 变现模式

1. 发布任务服务费 / 抽成（核心），雇主发单平台扣手续费

3. VIP 会员订阅收入
4. 提现手续费收益
5. 招募地推渠道、渠道商入驻收费
6. 广告招商、信息流广告
